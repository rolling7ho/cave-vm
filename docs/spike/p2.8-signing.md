# P2.8: ad hoc signing and vmnet

Raw results for the spike report (P2.11). Assumptions A5 and A6 in `ROADMAP.md`.

**Machine:** Apple M4 Pro, macOS 27.0.1 (26A434), Xcode installed, signed in to no paid Apple developer account. This is not the clean macOS 26 machine the roadmap asks for, so the result covers macOS 27 only until the script is rerun there.

**Method:** `scripts/spike/signing-check.sh`. It builds `hvf_probe` (creates a VM and runs a vCPU to its first trap) and a Swift vmnet probe (starts a shared-mode interface), then runs throwaway copies signed and installed in different ways. Rerun it on another machine to repeat.

## Result (2026-10-12)

| Case | Result |
| --- | --- |
| Linker signature only, no entitlement | Fails: `HV_DENIED` (exit 2) |
| Ad hoc signed (`codesign -s -`) with `com.apple.security.hypervisor` | **Works** |
| As above, plus a browser-download `com.apple.quarantine` flag | **Killed at launch** (exit 137, Gatekeeper) |
| As above, copied into a `bin` folder (what an install script does) | Works |
| Modified, then re-signed with `--preserve-metadata=entitlements,...` (what Homebrew does when it relocates a bottle) | Works, entitlement kept |
| Ad hoc with hardened runtime and the entitlement | Works |
| vmnet shared mode, linker signature, run as a normal user | Fails: `VMNET_FAILURE` (1001) |
| vmnet, ad hoc with `com.apple.vm.networking` | **Killed at launch** (exit 137): a restricted entitlement needs a provisioning profile |

## What it means

- **A5 holds on macOS 27.** Signing ad hoc with the hypervisor entitlement on the user's machine is enough to create VMs, with no paid account. It survives copying into a prefix and Homebrew-style re-signing.
- **A binary downloaded through a browser keeps its quarantine flag and is killed.** Install paths that use `curl` (the install script, Homebrew) do not set the flag. A browser download would need the flag removed or Developer ID signing and notarization, which matches the design's "later, if releases are downloaded through a browser".
- **A6 holds:** vmnet needs an entitlement that ad hoc signing cannot grant, so the userspace NAT (`smoltcp`, phase 3) is the right default.
